# Metalloids

A metalloid is a term used to describe elements on the periodic table that possess properties of both metals and non-metals.

There is no official definition or criteria for what qualifies an element as a metalloid, however generally, features such as electrical conductivity, appearance, natural state (solid, liquid, gas), plasticity, etc. are factors that are considered.
