# The arrival of 1million + context windows
Created: 2024-03-05 07:22

It seems like widely available 1+ context windows for LLMs are only a few months away. 
Based on the video by AI Explained, this is roughly 6/7 Harry Potter books worth of words.
I’m not sure how this affects individuals, but it seems like a major breakthrough for businesses.

1 token = 3/4 words.
The whole series of Harry Potter is roughly 1.08M words. So the comparison above checks out.

Beginning to approach potential use cases:
- can access and work with all files on your computer at once. After a few years of work, imagine what it will be capable of.
- Large amounts of an applications code base.
