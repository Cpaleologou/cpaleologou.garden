# Rare Earth Refining Cannot Target High Priced Materials

There is a prescribed order to removing elements from ore. That is, cerium may need to be refined first, then lanthanum, etc.
So the rarer, higher priced ores cannot be targetted. The extraction process must be performed for each subsequent existing mineral found in the ore prior to refining the mineral that is being targetted.
